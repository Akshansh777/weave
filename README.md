# WEAVE — AI Alumni Talent Engine

WEAVE transforms university alumni directories into talent and mentorship engines through intent-based matching (Asks & Offers), warm introductions, and skill gap analysis.

## Core Modules (In Progress)
- **Users Directory**: Student, alumni, faculty, and recruiter profiles.
- **Asks & Offers**: Real-time intent broadcasts for mentorship and referrals.
- **Opportunities Board**: Jobs, internships, and research fellowships.
